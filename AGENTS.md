## Design Context

**PRODUCT.md** and **DESIGN.md** at project root define the strategic and visual design system.

- **Register:** brand (portfolio — design IS the product)
- **Users:** potential employers, clients, collaborators
- **Brand Personality:** Modern, Creative, Dynamic
- **Design Principles:** Show don't tell, depth with purpose, confident simplicity, professional edge, effortless performance
- **Visual System:** Deep Navy (#1A2238) primary + Warm Gold (#D4A843) accent, Sora headings + Manrope body, 12px radius, flat-by-default with hover shadows, spring easing throughout
- **Anti-references:** Generic templates, tech-demo 3D, skeleton loaders, dark mode with purple/neon/glass
- **.impeccable/design.json** carries the full sidecar for live mode
- **.impeccable/live/config.json** configured for live mode on index.html
