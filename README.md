# Akhilesh Kalme — Portfolio

Full-stack developer portfolio built with HTML, CSS, and JavaScript. Modexa-inspired design with warm beige and vibrant orange palette.

## Tech Stack

- HTML5
- CSS3 (oklch color space, CSS Grid, custom properties)
- JavaScript (IntersectionObserver, Canvas 3D orbits)
- EmailJS for contact form

## Features

- Diagonal hero split with video background
- Bento grid about section with animated stats
- 3D glowing orbital canvas animation
- Responsive across all devices
- Cursor glow and scroll-triggered reveals

## Sections

- Hero / Home
- About (Who I Am)
- Services (What I Do)
- Tech Stack (Toolkit)
- Portfolio (My Work)
- Contact (Get in Touch)

## Deployment

Hosted on **Vercel** (or GitHub Pages). Auto-deploys on push to `main`.

## Local Development

Open `index.html` directly in browser — no build step required.
